# ShopSimulator→ALFWorld：GPU1单seed小规模迁移对照

本轮由用户确认：ShopSimulator训练12次更新，ALFWorld适配8次更新，固定24个目标评估任务，比较四种管理器。实验于2026-11-08启动，运行可跨日。配置、代码快照和所有实际结果以服务器`runs/transfer_gpu1_20261108/`为准。

## 比较对象

所有条件共享同一ShopSimulator SFT epoch3底座和冻结执行器；仅管理器LoRA更新。首先从6个源域训练任务收集公开轨迹，335条规则示例经工具校验后固定均衡选取128条，四类操作各32条。完成128次共同工具SFT预热。这个初始化记为M0，不是未训练的通用LLM。

| 条件 | 管理器初始化与训练 | 目标域训练 |
|---|---|---|
| target_initial | M0，仅共同源域工具SFT预热 | 无 |
| target_transfer | M0＋12步源域条件局部GRPO | 无 |
| target_adapted | 源域GRPO后＋8步目标全局GRPO | 有 |
| target_only_adapted | M0直接＋8步目标全局GRPO | 有 |

“仅目标域训练”仅指GRPO阶段；它仍共享源域SFT底座及工具预热。两个适配分支的目标训练步数、任务序列和采样组大小一致，但源域初始化分支有额外的源域训练成本，不构成累计训练算力相等的比较。

## 固定设置

- GPU：仅物理GPU1；CPU模拟器不使用GPU，不停止其他用户进程。
- seed与split_seed：233；一个训练seed，不作多seed稳定性结论。
- 源域：12次管理器更新，每组4条轨迹；第3/6/9/12步各增加4条原生快照局部续跑，共48条全局查询＋16条局部续跑。每次查询独立事实库。
- 目标域：public-v1无原生快照，因此适配采用全局GRPO；每分支8次更新×4条轨迹，共32条购物以外的真实操作轨迹。实际独立任务数另行统计。
- 目标数据：从官方train按六类任务各选8个，固定内部留出5个，剩43个为可用适配池；从valid_unseen按类各选4个，共24个评估任务。valid_seen仅留作manifest记录，本轮不查询。
- 源域诊断：internal_dev固定24任务，对M0和源域最终管理器作配对冻结评估；不使用原dev300和历史test900。
- 预算：源域最多12轮，目标最多30轮；actor最多256新token，manager最多192新token；同一环境所有条件预算相同。
- manager输入上限2048，actor输入上限6144；管理器每任务生成预算1536，总输入输出计费预算100000；检索最多6次。
- GRPO：lr=1e-5、clip=.2、KL beta=.01；源域local weight=.25。固定最终checkpoint，不按目标结果选模。
- 回报：`(strict_success + 0.1 * loose_reward) / 1.1`；本轮将非法操作与token成本系数设为0，作为监测指标保存，防止成本微差在全失败组内被标准化放大。

## 冻结和隔离

源域预热/GRPO只读取源域训练轨迹；目标冻结评估不更新任何参数，不向训练脚本回传目标评估轨迹。目标适配只允许train池任务。四种目标条件使用同一24任务全集、同一执行器、同一提示与生成预算，每任务清空事实记忆。经验库只读，当前实验为空。

每个子run保存receipt，包含模型、源码、数据和checkpoint身份；代码独立快照不随主项目变化。最终检查每条件ID唯一且与protocol完全一致、结果SHA一致、参数冻结、两种适配的训练任务序列一致，以及所有阶段actor张量哈希一致。

## 结果解释范围

本轮评估的是当前SCOPE基础实现的管理器迁移与少量适配，不能替代官方全部134任务或完整长期记忆研究。当前跨域状态主要采用公开原文引用、需求和尝试动作；完整ALFWorld类型化状态本体尚未补齐。不同任务间事实不共享，不能将任务分组称为跨会话记忆训练。

若目标域执行器能力处于地板，需把操作技能不足与记忆管理无效区分；本轮不会根据目标测试结果改执行器或扩大预算后重报原实验。参数变化、工具接受率也不等于任务效用。

报告严格成功数/率、宽松/严格奖励、错误购买或非法动作、长度终止、管理器操作统计、输入/输出token及局部续跑开销。配对簇bootstrap描述本批任务不确定性，不替代训练seed差异；全失败时退化的差值区间不能证明真实总体效果为0。

源域公开轨迹收集没有记录采样token，因此不能声称已获得整个训练准备过程的精确token总成本。已记录的GRPO、局部续跑和评估成本单独汇总。
